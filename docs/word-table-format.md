# Word 表格一键整理

脚本原版：[word_table_format.command](../scripts/document/word_table_format.command)。适用于 macOS 的 Microsoft Word 和已保存在本机的 `.docx` 文档。使用本机 `python3`、Python 标准库和本仓库 `lib/caption_re.py` 识别题注，不需要额外安装 Python 包或 Word 加载项。文档须已有名为 `ZDWP图名` 的样式；脚本直接复用其定义，缺少时在修改前报错。

## 使用

1. 在 Word 中打开要处理的文档；打开多份文件时，先切换到目标文档。
2. 在 Finder 中双击 `word_table_format.command`。
3. 等待终端显示完成信息。脚本会保存当前编辑内容，在原文档旁生成 `.bak-年月日-时分秒` 备份，再整理并保存原文档。

首次运行如果 macOS 询问是否允许终端控制 Microsoft Word，允许后即可通过 Word 文档接口处理。

每次运行会统一以下格式：

- 单元格、段落和文字底纹设为“无颜色”。
- 单元格内容水平、垂直居中。
- 外框和内部横竖线设为 **0.5 磅黑色单实线**，包括原先缺少的边框。
- 正文中的编号图名、表名统一套用文档已有的 **ZDWP图名** 样式，并清除这些题注的手工段落、字体格式覆盖。图名和表名使用同一个样式，原有编号及题注文字保持不变。

表格处理遍历正文、页眉页脚、文本框、脚注等区域，并递归处理嵌套表格，保留表格内容、字体、单元格宽度设置和表格样式名称。题注处理复用共享编号判据，并结合已有题注样式或相邻图、表识别，排除单元格内的文字和普通正文引用。写入前核对 Word 段落总数及每条题注的完整文本；遇到未支持的文档结构或并发编辑造成定位不一致时停止，避免改错段落。

以后新增表格、图名、表名或再次粘贴带格式的内容，重新运行即可；脚本不会作为后台服务自动监控文档。

也可以在终端运行，并传入路径校验当前处理对象：

```bash
/Users/tianli/Dev/tools/doctools/scripts/document/word_table_format.command "/完整路径/文档.docx"
```

不传路径时处理 Word 当前文档。`--help` 仅显示帮助，不修改文档。脚本使用 Word 文档对象接口，不模拟鼠标键盘操作，不使用剪贴板或切换窗口。

需要恢复时，先关闭对应 Word 文档，将备份复制为一个以 `.docx` 结尾的文件再打开核对。
